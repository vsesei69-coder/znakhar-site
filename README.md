# Знахарь

Медицинская косметика из эфирных масел ручной работы. Синтез ИИ-расчётов и древних знаний трав.

## Страницы
- `/` — главная: философия бренда, направления продуктов, каталог
- Корзина с онлайн-оплатой (в разработке)

## Технологии
Vite · React · TypeScript · Tailwind CSS

## Локальная разработка
```sh
npm install
npm run dev
```
