# Знахарь

Медицинская косметика из эфирных масел ручной работы. Синтез ИИ-расчётов и древних знаний трав.

## Страницы

Многостраничный сайт на React Router (`BrowserRouter`):

- `/` — главная: философия бренда, направления продуктов, 3 товара, ссылка на каталог
- `/about` — о фирме: сырьё, ИИ-расчёты, ручная работа
- `/philosophy` — философия бренда: 6 принципов
- `/catalog` — каталог с фильтром по категориям
- `/category/:slug` — категория: мази, кремы, эфирные масла, косметика, афродизиаки
- `/product/:id` — детальная страница товара
- `/contacts` — контакты (заполнить)
- `*` — 404

## Каталог товаров

Товары хранятся в `src/data/products.ts` (цены в ₽, категории — в `src/types/index.ts`).

## Технологии

Vite 5 · React 18 · TypeScript · Tailwind CSS 3 · React Router 7 · Framer Motion · Sonner

Тёмно-синяя тема: `.dark`-палитра задана в `src/index.css` (фон `222 35% 8%`, янтарный primary, изумрудный accent).

## Локальная разработка

```sh
npm install
npm run dev
```

Продовая сборка:

```sh
npm run build
```

## Деплой (GitHub Pages)

Пуш в ветку `main` автоматически собирает сайт и публикует на GitHub Pages (workflow `.github/workflows/deploy.yml`).

- URL: `https://<user>.github.io/znakhar-site/`
- `base` в `vite.config.ts` — `/znakhar-site/`. Для кастомного домена замени на `/`.
- SPA-роуты на Pages работают через `public/404.html` + скрипт восстановления URL в `index.html` (при прямом заходе на `/catalog` и т.п.).
- Включить деплой: **Settings → Pages → Source: GitHub Actions**.
